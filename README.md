# GitHub Skills Test Repositories for Certification Exam Prep

This repository is a curated set of compact GitHub Skills practice repositories built to support GitHub certification exam preparation. Each mini-repository focuses on a common exam scenario such as repository management, branches, pull requests, GitHub Pages, GitHub Actions, and security best practices.

## Purpose

Use these repos to practice:

- Creating and cloning repositories
- Branching and merging strategies
- Pull requests and code review workflows
- GitHub Pages deployment
- Automating tasks with GitHub Actions
- Managing secrets, protections, and repository settings
- Understanding common GitHub certification objectives

## Repository layout

- `skills/README.md` — index of practice repositories
- `skills/01-intro-to-github/README.md` — repository basics and markdown workflow
- `skills/02-branching-and-collaboration/README.md` — branching, commits, and pull requests
- `skills/03-github-pages/README.md` — static site publishing
- `skills/04-github-actions/README.md` — automation and CI/CD
- `skills/05-security-and-governance/README.md` — branch protection and secure flows

## Suggested exam-prep flow

1. Start with the introductory repo to confirm the basics.
2. Practice branching and collaboration workflows.
3. Deploy a simple static site with GitHub Pages.
4. Use GitHub Actions to automate checks.
5. Review repository security and governance settings.

These repos are intentionally lightweight so they can be used as isolated test fixtures during study sessions or labs.
