# Intro to GitHub

## Exam focus

This repository is designed for basic GitHub certification prep covering:

- creating a repository
- cloning locally
- editing files in a repo
- creating commits
- using Markdown for documentation

## Practice tasks

1. Clone the repository locally.
2. Open the `README.md` file and add a short introduction.
3. Create a new markdown file named `notes.md` with two bullet points about GitHub basics.
4. Commit the changes with a clear message.
5. Push the branch and review the repository history in GitHub.

## Example Markdown

```md
# GitHub Basics

- GitHub is a platform for hosting and collaborating on code.
- Repositories store project files and documentation.
```

## Skills practiced

- Repository management
- Commit discipline
- README authoring
- Basic GitHub workflow
