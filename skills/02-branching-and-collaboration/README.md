# Branching and Collaboration

## Exam focus

This practice repository covers collaboration tasks relevant to GitHub certifications:

- creating branches
- making commits on feature branches
- opening pull requests
- reviewing changes
- merging updates safely

## Practice tasks

1. Create a branch named `feature/update-docs`.
2. Edit `README.md` to add a new section called "Collaboration workflow".
3. Commit the change.
4. Open a pull request comparing the branch with `main`.
5. Merge the pull request after review.

## Suggested review checklist

- Is the change easy to understand?
- Does the branch contain a focused change?
- Is the commit message descriptive?
- Are updates linked to the correct task or issue?
