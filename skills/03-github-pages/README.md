# GitHub Pages

## Exam focus

This repository is designed to practice static site publishing using GitHub Pages.

## Practice tasks

1. Create a simple `index.html` page.
2. Add page content such as a landing page or product summary.
3. Enable GitHub Pages from the repository settings.
4. Confirm the site is published from the `main` branch or `/docs` folder.
5. Check the live URL and verify it loads correctly.

## Example page structure

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8" />
    <title>GitHub Pages Practice</title>
  </head>
  <body>
    <h1>GitHub Pages Practice</h1>
    <p>This site was deployed using GitHub Pages.</p>
  </body>
</html>
```

## Skills practiced

- GitHub Pages setup
- Static website publishing
