# Security and Governance

## Exam focus

This repo introduces security and governance tasks that appear in GitHub certification prep.

## Practice tasks

1. Review repository settings for visibility and access.
2. Configure branch protection rules for `main`.
3. Require pull request reviews before merging.
4. Add or review a repository secret used by automation.
5. Verify that protected branches restrict direct pushes.

## Suggested checklist

- Default branch is protected
- Direct pushes are blocked
- Pull requests are required for changes
- Review requirements are enabled
- Sensitive values are stored as secrets, not plaintext

## Skills practiced

- Branch protection
- Security review
- Access management
- Secure automation practices
