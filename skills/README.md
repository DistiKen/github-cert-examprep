# GitHub Skills Practice Index

This directory contains small, exam-oriented GitHub Skills repositories designed for hands-on certification practice.

## Available practice repos

1. [01-intro-to-github](./01-intro-to-github/README.md)  
   Focus: repository creation, file editing, commits, and Markdown basics

2. [02-branching-and-collaboration](./02-branching-and-collaboration/README.md)  
   Focus: branches, pull requests, code review, and merging

3. [03-github-pages](./03-github-pages/README.md)  
   Focus: static site publishing with GitHub Pages

4. [04-github-actions](./04-github-actions/README.md)  
   Focus: workflow automation, CI, and branch validation

5. [05-security-and-governance](./05-security-and-governance/README.md)  
   Focus: protection rules, secrets, and repository security configuration

## Usage

Each folder is a self-contained mini-repository that can be cloned, modified, and used for a focused exam preparation exercise. The goal is to simulate common GitHub certification scenarios in a minimal environment.
